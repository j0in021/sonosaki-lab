## 総合判定

**現状は試作として一部成立しているが、「各研究室に妥当な3つの推薦根拠がある」という中核要件には不合格。進路未定の高校生にとって最適な方法とも判断できない。**

最優先は質問数の増減ではなく、質問と実際の研究内容の対応を直すことである。そのうえで、まだ研究を知らない人が内容を知ってから関心を答えられる探索を試す必要がある。

- **誤った根拠による推薦を実再現した。** ゲーム理論を遊びの面白さ、植物の運動をスポーツの上達に結び付ける例がある。
- **大分類が合っていても3根拠は成立しない。** スポーツ法の研究者を、身体動作や技能向上への関心で推薦する例もある。
- **目的への設計上の不足がある。** 入口・テーマへの58個の肯定があっても、問い・活動への肯定がない合成経路は155問・推薦0件になる。実生徒の発生率や離脱率を測った結果ではない。
- **要件違反の操作不具合もある。** 希望件数を変えて過去の回答を編集すると、指定した質問が別の質問に置き換わる。
- **統計的最適性は未検証。** 未校正であることの開示は適切だが、情報利得の最大化だけでは研究理解や興味の発見を最適化したことにならない。

公開サイト・コード・データ・要件定義は変更していない。この総合報告は修正方針と受入条件の提案であり、修正完了や改善効果の実証を意味しない。

### SR-02 / P1 / 確認済み：分野の一致を個別の問い・活動の証拠として扱っている

対応：E2、RQ-01。箇所：`scripts/build_questions.py:74-78`、`site/engine.js:34-36`、F08・F09・F14。

溜箭将之先生 `utokyo-c38bfde32a4e` はスポーツに関する法学を扱うが、「上手な人の動き」「体の上達」に対する回答で推薦される。合法24回答、希望20件へ変更、推薦seed=0で9位。[公式紹介](https://www.j.u-tokyo.ac.jp/faculty/tamaruya_masayuki/)にはスポーツ団体の統治に関する論文が掲載されているが、これを身体技能の質問への対応証拠にはできない。タグの語義修正だけでは解消しない問題である。

現行は3理由すべてに説明または一覧のURLを付ける。**同じURLを使うこと自体は問題ではない。** 一つの資料が3内容を裏付けることはある。問題は、それぞれの具体的な問い・活動を支える箇所や関係を確認せず、タグとURLの存在だけで通している点である。

**修正・受入条件：** 各推薦理由に、回答ID、意味上異なる理由、研究室側の確認済み内容、出典URLと該当箇所、確認日を保存する。未確認の対応は3根拠へ計上しない。スポーツ法には権利・競技団体・ルールなど、公式内容に合う問いを確認して結び付ける。3理由の全件機械検査に加え、分野別の正例・負例を内容レビューする。成果の出典と推薦の対応根拠は分ける。

## 元の要望と要件定義の整理

以下はバグと分けて扱う仕様上の選択である。今回の会話だけから「未承認で変更した」と断定しない。

- 「必ず希望N件」と、後から加わった「3根拠を最低限持つ」は、根拠が得られない回答で同時に保証できない。v1.2は不足を正直に示す合理的な選択をしているが、「最大N件」という制約を維持して説明する必要がある。
- 「全研究室への公平な到達」の検査対象は2,562件。264件を含む全件確認とは呼べない。候補レコードと実際の研究室・教員の単位も区別する。
- 「統計的最適問数」は未達であり、可変化と情報利得の実装をもって達成とはしない。仮定を校正することと、大学研究への関心を育てる目的に方法を合わせることは別々に必要である。
- 要件担当が集計し、総合側も確認したところ、対象2,562件中2,291件に成果欄がない。これは成果が存在しないという意味ではなく、各研究室の成果説明を揃える当初の作業範囲に残りがあるという意味である。

## yes/noを維持する推奨方針

次の改訂候補は、**身近な入口 → 短い研究例 → 理解確認 → 関心の二択 → 研究室側の裏付けと対応する3理由の確認 → 候補の比較**とする。最適と実証された方式ではなく、現在の具体的な問題を解消するために比較すべき案である。

理解確認・関心・続行の問いを分ければ、第三の回答選択肢を加えずに設計できる。根拠の数を満たすためのyes誘導は避ける。紹介例が好意的すぎて同意を誘わないかも検査する。広い関心には複数分野の比較、深い関心には近い候補の比較を試せるが、関連性・公平さとの兼ね合いを実測する。

優先順は、SR-01/02の意味的な根拠修正 → SR-05/07の操作・保存修正 → SR-03/04の理解と質問内容 → SR-06の対象拡充と公平性 → 利用者比較による方式・終了条件の採択。操作不具合の修正は根拠監査と並行してよい。

## 最適な方法を選ぶための評価計画

1. **内容検査を先に行う。** 研究者・分野知識のあるレビュー担当が、質問から個別研究への対応を確認する。語義混同、隣接分野、一般論から個別活動への飛躍を含む負例を持つ。自動タグから作った正解だけで評価しない。
2. **高校生の理解を確認する。** 進路未定度、学年、既知の関心が異なる参加者に、質問と推薦理由を自分の言葉で説明してもらう。noの理由を観察する。少人数の予備試験は不具合発見用であり、統計的優越性の証明にはしない。
3. **主指標を先に決める。** 例として「初めて知った研究を一つ、その内容と気になる理由を説明できた割合」。条件を知らない評価者が共通基準で採点する。副指標は、理由の納得、未知分野の理解、次に読む資料の選択、時間、負担、自発中断。クリック数だけで興味形成を判定しない。
4. **修正後の同じデータで比較する。** 誤った推薦根拠を直したうえで、現在の質問中心方式と教材付き方式を比較する。N件・3根拠条件を揃え、無作為割付を行う。結果内の多様性は別段階で比較し、変更効果を混ぜない。
5. **効果と負担の基準から人数・終了条件を決める。** 検出したい改善幅と許容負担を事前に決め、予備データから必要人数を設計する。調整用と評価用の参加者を分離し、効果量と不確実性を報告する。固定の問数ではなく、目的達成と負担を両立する可変方針を比較する。
6. **追跡と同意。** 説明・必要な同意を整えた試験で、後日に公式資料閲覧や進路対話へつながったか確認する。公開サイトへ無断で解析を追加しない。大学受験への関心と、実際の出願・学力の長期効果を分ける。

[OECDのCareer conversations](https://www.oecd.org/en/publications/career-conversations_15b83760-en.html)は進路対話と後年の成果との関連を扱い、先生に見せるメモの方向性を支える。ただし、このアプリの因果効果を示すものではない。[O’Keefeらの関心発達研究](https://paulokeefe.com/wp-content/uploads/2024/09/OKeefe-Dweck-Walton-2018-Psych-Science.pdf)や[Dewの適応選好測定](https://pubsonline.informs.org/doi/10.1287/mnsc.2023.03775)も方法を考える参考であり、この高校生向け製品の最適方式や問数を決める直接証拠ではない。各研究の対象・取得範囲・限界は[目的レビュー](review-2026-10-28-purpose.md)に記載している。

## 維持すべき点と限界

yes/no、出典への導線、未確認成果の明示、根拠不足時の非水増し、途中結果と続行、回答保存、同条件抽選、全件到達検査には価値がある。これらを土台に、内容の妥当性と対象者の体験を加えて検証する。

今回の総合レビューは指定コミットのコード・保存データと選択した一次資料を対象とする。全研究室の現在の実態、全URL、実生徒の理解・疲労・満足、実際の表示頻度は未検証。今回ブラウザーでの全操作や配信資産の再照合は行っていない。具体的反例から全件の誤分類率を推計せず、提案した新方式の優越性も未実証とする。
