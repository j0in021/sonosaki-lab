## 全2,826件に適用する機械検査

`npm run content:check` は全IDを走査し、未確認への根拠流入、台帳と生成物の不一致、質問と根拠の対応ずれ、重複説明・質問、不正文、未確認成果の表示、件数不整合を拒否する。GitHub公開前の必須工程に追加した。

取込側 `scripts/evidence_data.py` でも説明重複・既知の不正文・質問形式を拒否する。現在の161件は通過した。説明重複・不正文・質問形式・質問重複・facet重複・出典箇所欠落の6種類を拒否する回帰テストを追加した。

機械検査は、同じURL内の正しい見出しを読んだか、3質問の意味が十分異なるかまでは証明しない。この境界を自動合格と表示しない。未確認2,665件の公式内容を再調査したという意味でもない。

## 人が行う取込確認

今後の根拠の追加・変更では、各IDについて (1)研究者と組織の一致、(2)公式本文の見出しと対象箇所、(3)同じ研究例での3facet対応、(4)時期・計画・成果の区別、(5)理解できなかった高校生にも伝わる別説明を記録する。要修正は推薦対象にしない。レビューされた入力版をhashで固定し、修正後の本文を再確認してから統合する。

全件再調査は本人の方針で停止している。全件対策は検査と取込条件を全IDへ適用することであり、未確認の意味を推測で埋めたり、説明を一括生成して確認済みに変えたりしない。
