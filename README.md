# その先ラボ

高校生が研究例を読み、はい／いいえで関心を探す静的Webアプリ。

確認済み161件を推薦し、未確認2,665件を明示する版を公開済みです。最新の件数は [確認進捗](data/review-progress.json) を参照。

## 修正した仕組み

希望件数1〜20を選び、広い入口→公式情報に対応した研究例→理解確認→テーマ・問い・取り組みの順に答えます。理解のnoには別の説明を出し、興味の否定として扱いません。3例ごとに続けるか選べます。推薦は3つの個別対応が揃う場合のみ。全件の研究紹介は別の一覧で検索できます。

「気になる」の保存・解除、編集中の再開、個別出典付きのメモに対応。データは端末内のlocalStorageだけに保存し、外部APIや解析タグはありません。

## ローカル実行

Node.js 22以降、Python 3。外部npm依存なし。

```sh
npm test
npm run check
npm run audit:check
npm run dev
```

`http://127.0.0.1:4173/`で確認。カタログ更新は既存CSVを明示し、[確認手順](docs/individual-review-workflow.md)に従います。

## 公開条件

根拠台帳を承認本文ハッシュと照合し、質問・説明・根拠が実行時にも一致する場合だけ推薦します。変更後は内容レビューと承認更新が必要です。

`npm run release:check`で確認済みだけが推薦対象であることを、`npm run content:check`で全2,826件と根拠台帳・質問の整合を検査します。未確認レコードは保全し、推薦対象に加えません。両検査は公開前の必須工程です。

## 限界

研究室・教員テーマ・センター等を含む2,826件と、元CSV2,988行の対応を維持しています。旧データの説明は個別照合が終わるまで確認済みの研究内容として使いません。成果の未記載は成果なしを意味しません。研究内容の紹介は、学生の活動・配属・募集を保証しません。

高校生による効果・負担の試験は未実施。質問数と方式が統計的に最適だとは主張しません。大学公式サービスではありません。
